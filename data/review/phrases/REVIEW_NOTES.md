# Extra customer phrases: what a reviewer must check

All by `claude_code (auto, pending mechanic sign-off)`, added in the accuracy round of 31 Oct 2026 from words the
evaluation's **dev split** did not recognise (the test split was never read). Loaded with
`cd backend && uv run python -m app.knowledge.phrases load` then `uv run python -m app.knowledge.embeddings sync`
(re-run both after every dataset re-import). They are never evaluation cases.

- `spelling_variants.yaml`: the spelling map (vaibreshan, tayar, horen, flikar, chabbi, neche, shoker, betri, injan,
  awaz, dhuan ...). **Check every spelling**; delete any that could mean something else.
- `spellings.yaml` (generated by `python -m app.knowledge.phrases draft`, do not edit by hand): 3,959 phrases. Each is
  an approved dataset phrase of the same fault with one word spelled another way, so no new fault facts. Texts equal
  to a held-out evaluation phrase are never generated.
- `hindi.yaml`: 24 Devanagari phrases for common Phase 1 problems with English glosses. A Hindi speaker should check
  each phrase and gloss.
